# 상품 이미지 교체 안내

현재 이 폴더의 이미지는 **placeholder(임시) SVG**입니다.
아래 파일들을 실제 상품 사진으로 교체하세요. (모델 컷 없이 제품 사진만)

| 파일명          | 용도                       |
| --------------- | -------------------------- |
| `product-1.svg` | 메인/정면 (썸네일 대표 이미지) |
| `product-2.svg` | 후면                       |
| `product-3.svg` | 디테일 컷                  |
| `product-4.svg` | 밑단 물방울 그라데이션 컷   |

## 교체 방법 (둘 중 택1)

1. **같은 경로 유지**: 새 이미지를 같은 파일명으로 저장하되 확장자가
   바뀌면(`.jpg`/`.png` 등) `src/lib/data/products.ts`의 `images` 배열
   경로도 함께 바꿔주세요.
2. **새 파일명 사용**: 원하는 이름으로 저장 후 `products.ts`의 `images`
   배열을 새 경로로 수정하세요.

권장 비율: 4:5 (예: 800×1000px). 갤러리/썸네일/확대(zoom)에 모두 사용됩니다.
